# Web Visual AI Editor V0.7 Font Spec

当前实现状态（2026-05-24）：V0.7 字体读取与切换代码已接入，复用 V0.2 样式编辑器的安全预览链路，新增 `fontFamily`、`letterSpacing` 字段展示与预览，记录自动生成 `fontChanges`；当前 V0.8 构建导出 JSON `version: "0.8"`，并新增本地字体读取入口。真实插件图标点击仍待 Chrome 手动验收。

## 1. 目标

V0.7 聚焦文本视觉改稿中最高频的字体信息表达：用户选中页面文本或包含文本的元素后，可以读取字体族、字号、字重、行高和字间距，进行临时预览，并把字体修改前后值结构化保存给 AI 或前端开发人员。

## 2. 功能边界

V0.7 做：

1. 读取选中元素 computed style 中的 `font-family`、`font-size`、`font-weight`、`line-height`、`letter-spacing`。
2. 在“样式编辑”的“字体 / 排版”分组中展示字体字段。
3. 支持 `fontFamily` 与 `letterSpacing` 文本输入，支持字号、字重、行高沿用现有控件临时预览。
4. 保存记录时从 `styleChanges` 自动派生 `fontChanges`。
5. 导出 JSON 为 `version: "0.7"`，记录中包含字体修改结构。
6. AI Prompt 输出“字体修改”段落，并把字体修改从普通样式修改中区分出来。

V0.7 不做：

1. 字体文件上传。
2. 云端字体管理。
3. 跨系统字体可用性保证。
4. 商用字体授权判断。
5. 自动识别网页使用的字体来源或本地字体库。

## 3. 数据设计

V0.7 复用 `StyleChange` 保存完整样式差异，同时新增字体专用子集：

```ts
type FontPropertyName =
  | "fontFamily"
  | "fontSize"
  | "fontWeight"
  | "lineHeight"
  | "letterSpacing";

type FontChange = {
  property: FontPropertyName;
  label: string;
  oldValue: string;
  newValue: string;
  unit?: "px" | "pt";
};
```

记录保存规则：

1. 元素级记录保存时，`fontChanges` 从字体相关 `styleChanges` 自动派生。
2. 页面级记录不保存 `styleChanges` 或 `fontChanges`。
3. 导入 V0.7 JSON 时保留合法 `fontChanges`。
4. 导入 V0.1 至 V0.6 JSON 时，如果旧 `styleChanges` 中存在字体字段，会自动派生 `fontChanges`，否则为空数组。

## 4. UX / UI

1. 字体能力放在既有“样式编辑”中，避免新增过多面板层级。
2. 分组标题从“排版”调整为“字体 / 排版”，字段顺序为：字体、字号、字重、行高、字间距。
3. 字体输入为普通文本框，允许用户输入 `Inter, Arial, sans-serif` 这类 fallback 字体栈。
4. 字间距为文本框，允许 `normal`、`0.4px`、`0.02em` 等浏览器可接受值；当前版本不做单位强制转换。
5. 临时预览沿用 V0.2 机制，未保存前可重置，不直接写入记录。

## 5. Prompt 输出

当记录包含字体修改时，Prompt 输出：

```text
- 字体修改：
  - 字体（fontFamily）: Arial, sans-serif -> Inter, Arial, sans-serif
  - 字间距（letterSpacing）: normal -> 0.4px
```

字体修改不再重复写入普通“样式修改”段，避免 AI 接收重复指令。

## 6. 验收标准

1. 选中文本元素后，“字体 / 排版”分组展示 `fontFamily`、`fontSize`、`fontWeight`、`lineHeight`、`letterSpacing`。
2. 输入字体栈、字号、字重、行高或字间距后，页面有临时预览且可重置。
3. 保存记录后，导出 JSON 为 `version: "0.7"`，且记录包含 `fontChanges`。
4. 复制 Prompt 时包含“字体修改”段落。
5. 导入 V0.7 JSON 后合法 `fontChanges` 保留。
6. 导入旧版本 JSON 后不报错，旧字体类 `styleChanges` 可被派生为 `fontChanges`。

## 7. 风险与降级

1. 部分浏览器会返回带引号或 fallback 的 `fontFamily`，V0.7 保留原始 computed 字符串，不尝试解析。
2. 输入不可用字体时，浏览器会按 fallback 渲染；V0.7 不承诺跨系统一致。
3. `letterSpacing` 可能为 `normal`，因此采用文本输入，避免错误地强制转换为数值。
4. Content Script 仍只在用户主动选中元素后读取 computed style，不读取输入框实际值，不上传页面内容。
