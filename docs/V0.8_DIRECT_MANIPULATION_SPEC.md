# Web Visual AI Editor V0.8 Direct Manipulation Spec

当前实现状态（2026-05-24）：V0.8 已接入 Figma-like 直接操作基础层，包含顶部“自动布局”模式、选中元素中部粉色拖拽横条、同父容器兄弟元素命中交换预览、交换位移动画、紫色虚线参考线/目标框/位置反馈、共享元素开关前置、本地字体读取入口与 JSON `version: "0.8"`。已通过 `npm run verify` 和 Chrome headless 页面内烟测，仍需 Chrome 真实插件手动验收。

## 1. 目标

V0.8 回应用户对“像 Figma 一样直接在内容区域操作”的诉求，把 V0.6 的“填写布局意图”推进为可见、可拖、可记录的页面内直接操作：

1. 用户在顶部浮动工具栏点击“自动布局”。
2. 用户选中页面元素后，元素中部显示粉色横向拖拽条，贴近 Figma / Sketch 直接操作手感。
3. 用户拖动横条压到同级元素时，页面按鼠标实际命中的元素进行精准交换预览，并出现目标元素框、紫色虚线参考线和位置标签。
4. 用户松开后，在同一父容器内调整该元素的 DOM 顺序，并自动保存布局记录。
5. 面板内共享元素能力以开关形式前置，开启后保存记录携带相似元素范围。
6. 字体面板提供“读取本地字体”入口，支持浏览器 Local Font Access 时读取系统字体；不支持时保留手动输入字体栈。

## 2. 做什么

V0.8 做：

1. 顶部工具栏新增“自动布局”模式。
2. Overlay 在自动布局模式下把选中框切换为紫色描边样式，避免大面积遮挡宿主页面视觉。
3. Overlay 在选中元素中部显示粉色横向拖拽条。
4. Content Script 支持拖动横条，在同一父容器内根据鼠标下真实同级元素计算交换目标，并在拖动过程中做实时 DOM 交换预览。
5. 拖动过程显示目标框、紫色虚线参考线和“交换第 N 位”位置反馈，并通过 FLIP 位移动画呈现目标让位。
6. 松开后移动 DOM 元素，并新增 `category: "layout"` 的记录，写入 `layoutContext` 和 `layoutIntent`。
7. 退出编辑器时恢复本次会话内由自动布局拖动产生的 DOM 顺序，避免污染宿主页面。
8. 相似元素面板新增“共享元素”开关，开启时高亮相似元素并影响后续记录保存范围。
9. 字体编辑新增本地字体读取按钮和下拉选择，失败时展示降级提示。
10. 导出 JSON 升级为 `version: "0.8"`，继续兼容导入 V0.1 至 V0.8。

## 3. 不做什么

V0.8 不做：

1. 不做完整 Figma Auto Layout 参数编辑器。
2. 不做跨父容器拖拽、自由绝对定位或画布层级面板。
3. 不做复杂 CSS Grid 二维落点推断，只支持基于同父容器兄弟顺序的基础换位。
4. 不保证所有网页都能读取本地字体；取决于浏览器 Local Font Access 能力、权限和页面上下文。
5. 不做字体上传、字体授权判断或云端字体管理。
6. 不做自定义永久参考线系统；当前紫色虚线参考线只服务自动布局拖动反馈与测距反馈。

## 4. 交互说明

自动布局模式：

1. 点击顶部工具栏“自动布局”。
2. 点击目标元素。
3. 观察选中框变为紫色描边，元素中部出现粉色横向拖拽条。
4. 拖动横条压到兄弟元素上，页面显示紫色虚线参考线、目标框和位置标签，并实时预览元素交换。
5. 松开后，当前预览位置被确认，并写入一条布局记录。
6. 退出编辑器后，自动恢复拖动前的 DOM 顺序；导出的记录仍保留修改意图。

共享元素：

1. 选中元素后，相似元素区显示匹配数量与匹配特征。
2. 打开“共享元素”开关后，系统高亮整组相似元素。
3. 后续保存记录时，记录写入 `sharedGroup`，表示同一批元素都应参考该修改。

字体：

1. 选中元素后，在“字体 / 排版”分组中查看字体族、字号、字重、行高、字间距。
2. 点击“读取本地字体”后，如果浏览器支持并授权，字体下拉展示本机字体族。
3. 如果读取失败，用户仍可在字体栈输入框中手动输入。

## 5. 数据

V0.8 不新增新的顶层字段，沿用：

1. `layoutContext`：记录拖动完成后的父容器布局上下文。
2. `layoutIntent`：记录拖动方向和“从第 X 位移动到第 Y 位”的 note。
3. `sharedGroup`：记录共享元素批量范围。
4. `fontChanges`：记录字体类样式差异。

导出版本升级为 `0.8`。导入 V0.7 时保留合法 `fontChanges`；导入 V0.6 / V0.7 / V0.8 时保留合法 `layoutContext` 与 `layoutIntent`；导入 V0.5 至 V0.8 时保留合法 `sharedGroup`。

## 6. 验收标准

1. 顶部工具栏出现“自动布局”按钮。
2. 点击“自动布局”后，选择元素会出现紫色描边选中框和元素中部粉色横向拖拽条。
3. 拖动横条时，页面出现紫色目标框、紫色虚线参考线和“交换第 N 位”标签。
4. 在同一父容器内拖动压到兄弟元素时，元素顺序实时预览交换并有位移动画；松开后确认位置并新增布局记录。
5. 导出 JSON 为 `version: "0.8"`，布局记录包含 `layoutContext` 和 `layoutIntent.note`。
6. 退出编辑器后，拖动造成的 DOM 顺序恢复。
7. 相似元素区存在“共享元素”开关，开启后高亮相似元素并影响保存记录的 `sharedGroup`。
8. 字体区存在“读取本地字体”入口；支持时展示本地字体，不支持时展示降级提示，手动输入仍可预览。
