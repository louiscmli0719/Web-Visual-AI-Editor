# Web Visual AI Editor V0.5.5 UI Refresh Spec

## 1. Problem / Opportunity

V0.1-V0.5 的功能闭环已经完整（选元素 -> 评论 -> 样式 -> 测距 -> 共享分组 -> 导出），但 UI 需要从早期原型风格收敛为更像 Sketch 右侧 Inspector 的专业工具质感：哑光深黑面板、紧凑区块、深灰胶囊控件、弱边界、低发光。

V0.5.5 的机会：在不破坏现有功能的前提下，重构 UI 表层，让插件面板像设计工具属性面板，而不是悬浮装饰面板。

## 2. Goal and Success Metrics

目标：将 Panel 视觉升级为 Sketch-style matte inspector，Overlay 保持红粉 / 红色高对比反馈，所有 V0.5 功能完整可用。

当前实现状态（2026-05-26）：已通过 Vibma 读取 Figma 当前选中的 `工具栏`、`样式`、`记录`、`评论` 画板，并按设计稿二次对齐插件 UI。顶部工具栏使用黑色胶囊、34px 图标按钮、记录文字与蓝色数量徽标；Panel 使用 383px 深色毛玻璃 Inspector、16px 内边距、24px 区块间距、8px 深灰控件；Panel 顶部功能条承载属性/记录切换、共享元素开关和重置按钮，控件高度收紧为 42px 级，并作为可拖动区域。当前已接入正式浏览器图标资源，相似元素区长 class / selector 采用单行裁切与 title 悬停完整查看，保存按钮禁止文字换行。代码已通过 `npm run verify`（104 个测试 + TypeScript + Vite build），并可通过 `npm run package` 输出 `Packages/web-visual-ai-editor-v0.8.0.zip`，等待 Chrome 真实插件手动视觉复核。

成功标准：

1. 哑光深色主题：Panel 主背景按设计稿使用 `rgba(24, 24, 24, 0.9)` 并保留 8px 背景模糊，文字高对比。
2. Sketch Inspector 质感：深灰胶囊控件、弱边界、少阴影、无大面积 blur。
3. 浮动工具栏顶部固定，浏览、选择、测量、评论、自动布局、记录、关闭等核心操作可用。
4. 蓝紫强调色只用于记录数量徽标与 Panel 焦点状态；工具栏 active 态使用中性灰色胶囊，避免遮抢宿主页面视觉。
5. Overlay 选中框、评论编号点、测距线和相似元素高亮使用红粉 / 红色高对比反馈。
6. 记录列表使用紧凑 inspector 行块，不使用独立发光卡片。
7. 所有 V0.5 功能（评论、样式、测距、共享分组）在新 UI 下正常工作。
8. Panel 宽度默认 383px，内容在桌面浏览器内可滚动。
9. Panel 默认仍贴右侧显示，用户可拖动顶部功能条自由移动，拖动后不会超出视口。
10. 数值输入采用左侧数值、右侧单位的胶囊样式，默认 `px`，可切换 `pt`，清空后自动归零。

## 3. Target Users and Main Scenarios

| 用户 | 场景 | V0.5.5 要解决的问题 |
|---|---|---|
| AI 编程用户 | 长时间使用工具标注页面 | 深色工具面板减少眼疲劳，控件层级清晰 |

## 5. Component Architecture

### 5.1 Floating Toolbar

- Top fixed toolbar outside Panel scroll area.
- Figma-aligned matte dark pill: `rgba(40, 40, 40, 0.9)` background, 1.5px translucent border, 6px padding, 10px gap and 4px backdrop blur.
- Mode buttons are compact icon-only 34px controls with `aria-label`; order is browse / select / measure / comment / auto-layout; icons use SVG path data exported from the Figma toolbar via Vibma.
- Hover and active mode use a circular 38px neutral `rgba(80, 80, 80, 0.6)` fill.
- Record button keeps icon + “记录” text + blue `#535dff` count badge; JSON export/import/Prompt copy remain in the Panel delivery bar, not the floating toolbar.
- Hover state uses subtle field lift.
- 评论按钮进入 comment mode：点击宿主页面元素后，在元素附近显示黑色快速评论弹窗。

### 5.1.1 Draggable Panel

- Panel 默认保持右侧 Inspector 位置，减少首次进入编辑模式时的认知成本。
- 用户可拖动 Panel 顶部功能条移动面板，避开正在检查的页面区域。
- 拖动位置只在当前编辑会话内生效，不写入 JSON、不写入本地存储。
- 拖动过程使用 Pointer Events，并约束在视口 8px 安全边距内，窗口尺寸变化后自动夹回可见区域。

### 5.2 InspectorSection

`InspectorSection` replaces the previous heavy section wrapper. It is a semantic layout wrapper only; visual hierarchy comes from spacing, titles, dividers and compact controls rather than heavy cards.

### 5.3 Element Info Panel

Inspector section with compact tag, selector and numeric control cells:

```text
p                    962 x 23 px
----------------------------
位置与尺寸
[ X 445 ] [ Y 408 ]
[ W 962 ] [ H 23  ]
> 高级信息
```

### 5.4 Style Editor

Sketch-like rows with labels on the left and rounded dark controls on the right。长度输入使用左数值、右单位的胶囊控件，默认 `px`，支持 `pt` 切换，空输入自动归零：

```text
样式编辑
> 外观
文本颜色      [ rgb(148, 163, 184) ]
背景色        [ rgba(0, 0, 0, 0)   ]
圆角          [ 12 | px ▾          ]
> 排版
字号          [ 16 | px ▾          ]
```

### 5.4.1 Length Unit Capsule

- 数值输入左侧只接受数值，右侧单位下拉默认 `px`。
- 从 `px` 切到 `pt` 时自动换算，不要求用户手算。
- 清空数值后自动回到 `0`，避免出现空字符串状态。
- Tab 顺序保持为“数值 -> 单位 -> 下一项”，不打断键盘录入。

### 5.5 Measurement Panel

Measurement results reuse the same numeric control cells as element info. Pair results can use a soft blue-violet section background, but not a large glowing card.

### 5.6 Similar Elements Panel

Collapsible inspector section. Count/status uses `StatusBadge`; target selectors render as compact dark rows. Long primary features and selectors must stay inside the 383px inspector: visible text uses ellipsis, full selector is available via native `title`, and the list must never create horizontal overflow.

### 5.7 Comment Editor

Textarea, metadata selects and action buttons use matte rounded controls. Page comments and element comments remain visually separate but not card-heavy.

快速评论弹窗复用相同的 textarea / select / button 视觉，使用粉紫圆形编号强调评论锚点；保存后仍走既有元素评论记录，不改变 JSON 数据格式。

### 5.8 Record List

Compact inspector row blocks:

```text
修改记录       3 / 8
[ 类型 ] [ 状态 ] [ 范围 ]
[ record row ]
[ record row ]
```

Row hover:

- Slight background lift.
- No scale.
- No glow.

### 5.9 Overlay Element Label

- Reuses `overlay-root.ts` Shadow DOM layer.
- Dark matte label.
- Red-pink border/text to match high-contrast selection feedback.
- Small mono font (11-12px).
- Avoid injecting extra host-page styles.

## 7. Non-goals

V0.5.5 不做：

1. 改变功能逻辑（所有 V0.5 功能保持不变）。
2. 新增数据能力或业务闭环（本轮只补充拖动面板等轻量 UI 交互）。
3. 响应式适配移动端（Panel 仍为桌面浏览器设计）。
4. 主题切换（仅深色主题）。
5. 自定义颜色（固定蓝紫强调，不做主题切换）。
6. 动画库（仅 CSS transitions）。
7. 国际化（仍为中文）。

## 10. Risks and Edge Cases

| 风险 | 影响 | 降级方案 |
|---|---|---|
| 深色主题对比度不足 | 可访问性问题 | 确保文字对比度 >= 4.5:1 (WCAG AA) |
| 控件过于紧凑 | 信息难读 | 保持 40px 主控件高度和 22px section gap |
| Panel 宽度增加导致遮挡 | 小屏幕体验差 | 保持 383px 设计宽度并用 `min(383px, calc(100vw - 28px))` 适配小屏，内容自适应滚动 |
| Panel 拖到目标元素上方 | 标注时遮挡页面 | 顶部功能条可拖动，用户可临时移开面板 |
| Panel 被拖出视口 | 无法继续操作 | 拖动和窗口 resize 时保持 8px 安全边距 |
| Overlay 颜色过淡 | 网页上不可见 | Overlay 继续使用红粉 / 红色高对比反馈 |
