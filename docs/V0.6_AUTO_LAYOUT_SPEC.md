# Web Visual AI Editor V0.6 Auto Layout Spec

当前实现状态（2026-05-26）：V0.6 自动布局辅助代码已接入，包含父容器布局读取、布局辅助面板、布局意图保存与 AI Prompt 布局段落；当前 V0.8 构建继续保留 `layoutContext` / `layoutIntent`，并在 V0.8 增加同父容器直接拖动换位。为避免无效功能占据样式面板，当前 Inspector 只在父容器为 flex / grid 且存在可操作兄弟元素时展开完整自动布局参数；普通 block / inline 或无兄弟元素时仅在自动布局模式下给出轻量降级提示。真实插件图标点击仍待 Chrome 手动验收。

## 1. 目标

V0.6 的目标不是做完整 Auto Layout 编辑器，而是让用户在真实网页上选择元素后，能看到其父容器的基础布局上下文，并把“改为横向 / 纵向 / 居中 / 等距 / 16px gap”等意图结构化保存给 AI 或前端开发。

## 2. 范围

V0.6 做：

1. 读取选中元素的直接父容器。
2. 展示父容器 `display`、`flex-direction`、`justify-content`、`align-items`、row gap、column gap。
3. 展示当前元素在父容器中的序号和兄弟元素总数。
4. 支持用户保存布局方向、对齐方式、目标间距和补充说明。
5. 将布局上下文与布局意图写入 JSON 和 Prompt。

V0.6 不做：

1. 自动改写宿主页面布局。
2. 完整 Auto Layout / Figma 等价模型。
3. 多层父级自动推断。
4. 复杂响应式断点分析。
5. 网格单元、换行、对齐基线、容器查询等高级布局解析。

## 3. 用户流程

1. 用户进入编辑模式。
2. 用户点击某个 DOM 元素。
3. Inspector 展示“布局辅助”区块。
4. 区块显示父容器基础布局信息。
5. 用户选择布局方向、对齐方式，填写目标 gap 或备注。
6. 用户点击“保存布局意图”。
7. 记录列表新增一条 `category: "layout"` 的元素级记录。
8. 导出 JSON 或复制 Prompt 时包含布局上下文和意图。

降级规则：

1. 如果选中元素的父容器不是 flex / inline-flex / grid / inline-grid，Inspector 默认不展开自动布局参数。
2. 如果父容器没有可交换的兄弟元素，Inspector 默认不展开自动布局参数。
3. 用户显式进入“自动布局”模式时，可看到轻量提示，说明该元素当前不适合生成布局意图，避免保存无效记录。

## 4. 数据结构

V0.6 新增：

```ts
type LayoutContext = {
  parentSelector: string;
  parentTagName: string;
  display: "flex" | "inline-flex" | "grid" | "inline-grid" | "block" | "inline" | "other";
  flexDirection: string | null;
  justifyContent: string | null;
  alignItems: string | null;
  gap: { row: string; column: string };
  childIndex: number;
  siblingCount: number;
};

type LayoutIntent = {
  direction: "none" | "horizontal" | "vertical";
  alignment: "none" | "start" | "center" | "end" | "space-between";
  gap: string;
  note: string;
};
```

`EditRecord` 新增：

```ts
layoutContext?: LayoutContext | null;
layoutIntent?: LayoutIntent | null;
```

约束：

1. 页面级记录不保留布局上下文。
2. 旧版本导入时布局字段默认为 `null`。
3. `layoutIntent` 只来自用户主动保存，不从 DOM 自动推断修改建议。

## 5. UI 要求

1. “布局辅助”放在相似元素区块之后、测距 / 样式编辑器之前，但只在可产生作用的父容器场景中默认展开。
2. 未选择元素时，仅在用户已进入自动布局模式时显示空状态。
3. 无父容器、父容器不是 flex / grid 或没有可交换兄弟元素时，显示明确降级提示，不渲染方向、Gap、Padding、Margin 全量控件。
4. 常用方向、Gap、Padding、Margin 保持设计稿主视觉；父容器 selector、对齐方式和布局说明放入“高级布局信息”折叠区。
5. 用户修改方向、对齐、Gap 或说明后，显示轻量“布局意图尚未保存”提示和保存按钮。
6. 输入控件沿用现有深色 Inspector 表单样式，不引入会干扰宿主页面判断的强装饰。
7. 保存后清空布局输入，并给出“布局意图已保存。”反馈。

## 6. Prompt 要求

有布局字段的记录必须输出：

1. 父容器 selector 和 tag。
2. 当前 display、方向、主轴对齐、交叉轴对齐。
3. row / column gap。
4. 当前子元素位置。
5. 用户目标方向、目标对齐、目标间距和补充说明。

AI 应根据该段落找到需要调整的父容器，而不是只修改当前子元素本身。

## 7. 验收标准

1. 选中 flex 父容器内的元素时，Panel 显示父容器 selector、display、方向、对齐、gap 和子元素位置。
2. 保存布局意图后，记录列表新增布局记录。
3. 导出 JSON 为 `version: "0.6"`，记录包含 `layoutContext` 和 `layoutIntent`。
4. 复制 Prompt 时包含“布局辅助”段。
5. 导入 V0.1 至 V0.5 JSON 时，布局字段降级为 `null` 且旧记录可继续使用。
6. 退出编辑模式后宿主页面交互恢复正常。
