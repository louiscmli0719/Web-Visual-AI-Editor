# V0.3 Comment Enhancement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the V0.2 record model with `category` / `priority` / `status` / `interactionState` / `scope`, add inline edit + delete + state switching + filter, support page-level comments, and reshape the AI Prompt with grouped output. Keep V0.2 style preview intact and stay backward compatible with V0.1 / V0.2 JSON.

**Architecture:** Keep V0.2 MV3 architecture. All new logic lives in `extension/src/content/session-store.ts` (data), `extension/src/panel/*` (UI), and `extension/src/shared/prompt-template.ts` (output). No new background or overlay logic.

**Tech Stack:** Chrome Extension MV3, TypeScript, Vite, React, Vitest, Shadow DOM.
