# V0.8 Direct Manipulation Implementation Plan

状态：已执行，待 Chrome 真实插件手动验收。

## 1. 实现范围

V0.8 把用户截图中的核心交互拆成可交付的直接操作基础层：

1. 顶部工具栏新增“自动布局”模式。
2. Overlay 新增紫色直接操作选中态、横向拖手、目标框、参考线和位置标签。
3. Content Script 支持同父容器内拖动换位，并自动生成布局记录。
4. 退出编辑器时恢复本次自动布局拖动造成的 DOM 顺序。
5. 相似元素面板新增“共享元素”开关，开启后立即高亮相似元素。
6. 字体面板新增 Local Font Access 读取入口和字体下拉，保留手动字体栈输入。
7. 数据格式升级到 `0.8`，兼容导入 V0.1 至 V0.8。

## 4. 待验收

1. Chrome 中点击真实插件图标进入编辑器。
2. 点击顶部“自动布局”，选中元素后拖动紫色横条。
3. 确认参考线、目标框、位置标签可见。
4. 松开后确认 DOM 顺序临时改变，并新增布局记录。
5. 导出 JSON，确认版本为 `0.8` 且记录包含布局字段。
6. 退出编辑器后确认页面 DOM 顺序恢复。
7. 选中相似元素，打开“共享元素”开关，确认高亮和保存范围。
8. 点击“读取本地字体”，确认支持环境读到本机字体；不支持环境展示降级提示。

## 5. 风险

1. Local Font Access 取决于浏览器能力与权限，不保证所有页面可用。
2. 自动布局拖动只支持同父容器兄弟顺序，不支持跨容器或自由定位。
3. 某些网页脚本可能监听 DOM 顺序变化，自动布局拖动可能触发页面自身逻辑；退出编辑器会尽量恢复 DOM 顺序。
