# V0.7 Font Implementation Plan

状态：代码实现完成，`npm run verify` 已通过；Chrome headless 页面内 content script 烟测已验证字段展示、字体预览、记录保存、JSON 导出与 Prompt 复制，真实插件图标点击仍待手动验收。

## 1. 目标

在不扩大 V0.2 样式编辑器复杂度的前提下，补齐字体读取、预览、记录、JSON 导出和 Prompt 输出闭环。

## 2. 实施拆解

1. 数据版本与类型
   - `DATA_FORMAT_VERSION` 升级到 `0.7`。
   - `SUPPORTED_IMPORT_VERSIONS` 增加 `0.7`。
   - `EditorSession` 与 `EditorSessionExport` 支持 `0.7`。
   - 新增 `FontPropertyName` 与 `FontChange`。

2. 字体字段读取与预览
   - 在 `STYLE_PROPERTY_DEFINITIONS` 中新增 `fontFamily` 与 `letterSpacing`。
   - “排版”分组改为“字体 / 排版”。
   - `fontFamily` 与 `letterSpacing` 使用文本输入，避免错误强制单位。

3. 记录与导入兼容
   - 新增 `shared/font-changes.ts`，集中维护字体字段白名单与 `deriveFontChanges()`。
   - `addEditRecord()` 保存元素记录时从 `styleChanges` 派生 `fontChanges`。
   - 页面级记录清空 `fontChanges`。
   - 导入 V0.7 时保留合法 `fontChanges`；导入旧版本时从字体类 `styleChanges` 派生。

4. Prompt
   - `prompt-template.ts` 新增“字体修改”段。
   - 字体修改不重复写入普通“样式修改”段。

5. 验证
   - 补充 `style-inspector`、`session-store`、`prompt-template` 测试。
   - 已完整执行 `cd extension && npm run verify`：96 个单元测试、TypeScript、Vite build 通过。
   - 已完成 Chrome headless 页面内烟测：选择 `basic.html` 的 `#style-primary-button`，修改字体为 `Inter, Arial, sans-serif`、字间距为 `0.4px`，保存后导出 JSON `version: "0.7"` 且包含 `fontChanges`，复制 Prompt 包含“字体修改”和“字间距（letterSpacing）”。
   - Chrome 手动验收：选择 `basic.html` 中标题或按钮，修改字体/字间距，保存后导出 JSON 与复制 Prompt。

## 4. 风险

1. 字体可用性依赖用户系统与网页 fallback，V0.7 只记录意图，不保证渲染完全一致。
2. `fontFamily` computed 值可能包含引号、多个 fallback 或浏览器默认字体，导出时保留原始字符串。
3. 完整真实插件图标点击仍需要人工在 Chrome 中加载 unpacked extension 复核。
