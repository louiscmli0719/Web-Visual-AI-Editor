# V0.2 Style Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the V0.2 style editor on top of the V0.1 selection/comment flow, with computed style reading, safe preview, structured `styleChanges`, JSON import/export, and AI Prompt output.

**Architecture:** Keep V0.1 MV3 architecture. Add a focused style domain under `extension/src/content/` and `extension/src/shared/`, then expose style controls through existing React Panel. Preview writes temporary inline styles and restores original inline values on reset/exit.

**Tech Stack:** Chrome Extension MV3, TypeScript, Vite, React, Vitest, Shadow DOM.

---

- [ ] **Step 3: Implement style inspector**

Implement:

```ts
export function readStyleSnapshot(element: Element): StylePropertySnapshot[] {
  if (!(element instanceof HTMLElement)) {
    return [];
  }

  const style = window.getComputedStyle(element);
  return STYLE_PROPERTY_DEFINITIONS.map((definition) => ({
    ...definition,
    value: style[definition.property]
  }));
}
```

Use a fixed `STYLE_PROPERTY_DEFINITIONS` array so Panel order is stable.
